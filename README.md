# Don't Pay for Screenwriting Software 🎬✍️

A lightweight, distraction-free, and 100% free web-based screenwriting tool. Built entirely using web technologies, this application gives you the core formatting power of premium screenwriting software without the hefty price tag, subscriptions, or watermarks.

Now upgraded into a **Progressive Web App (PWA)**, you can install it directly onto your desktop or mobile device and write your scripts seamlessly—even when you are entirely offline.

## ✨ Features

- **Standard Script Formatting:** Easily handle Sluglines, Actions, Character names, Parentheticals, and Dialogues automatically.
- **Progressive Web App (PWA):** Install it as a standalone app on iOS, Android, macOS, or Windows.
- **Offline Capabilities:** Fully functional without an internet connection. Write on a plane, in a subway, or out in nature.
- **Privacy-First:** Your scripts are your own. All data is processed locally in your browser—nothing is uploaded to external servers.
- **Ultra-Lightweight:** Fast loading speeds, zero bloat, and a distraction-free interface.
- **Open & Customisable:** Built on clean HTML/JS, allowing you to tweak the code easily to suit your specific workflow.

## 📲 Installation (PWA)

To install this app on your device:

### On Desktop (Chrome / Edge / Brave):
1. Visit the live site link above.
2. Click the **Install Icon** (a monitor with an arrow) on the right side of the URL address bar.
3. Click **Install**. It will now appear as a dedicated app in your applications list.

### On iOS (Safari):
1. Open the live site in Safari.
2. Tap the **Share** button (square with an up arrow).
3. Scroll down and select **Add to Home Screen**.

### On Android (Chrome):
1. Open the live site in Chrome.
2. Tap the **Three Dots** menu icon in the top right corner.
3. Select **Install app** or **Add to Home screen**.
